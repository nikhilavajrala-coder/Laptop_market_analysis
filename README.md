# Laptop_market_analysis

## Overview

This project analyzes laptop listings collected from Flipkart using Python. The analysis focuses on laptop prices, brands, RAM, processors, discounts and ratings.

## Technologies Used

- Python
- Requests
- BeautifulSoup
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Workflow

1. Scraped laptop listings using Requests and BeautifulSoup
2. Cleaned and prepared the collected data
3. Performed exploratory data analysis using Pandas and NumPy
4. Analyzed pricing, brands, RAM, processors, discounts and ratings
5. Created visualizations using Matplotlib and Seaborn

## Key Analysis

- Laptop price distribution
- Brand-wise pricing
- RAM and processor trends
- Discount analysis
- Rating analysis

## Files

- `laptop_analysis.ipynb` — Main analysis notebook
- `laptop_data.csv` — Dataset
- `visualizations/` — Generated charts
